# nickaqmal02/tap

Homebrew formulae by nickaqmal02.

## StudyNotch

A pomodoro timer and habit tracker that lives in your MacBook notch.

```
brew install nickaqmal02/tap/studynotch
brew services start studynotch
```

Needs macOS 13 or later and Apple's Command Line Tools (`xcode-select --install`). Source: https://github.com/nickaqmal02/ApexAgent
